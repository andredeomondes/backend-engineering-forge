# Checklist de aceite — Order Workbench CLI

## Correção

- [ ] Valida todos os campos obrigatórios.
- [ ] Acumula mais de um erro por pedido.
- [ ] Calcula dinheiro apenas em centavos inteiros.
- [ ] Agrupa quantidade e valor por status.
- [ ] Separa pedidos válidos e inválidos preservando o índice.
- [ ] Não altera pedidos ou itens recebidos.

## Qualidade

- [ ] Nomes descrevem intenção.
- [ ] Funções possuem uma responsabilidade clara.
- [ ] Não há estado global para o contador.
- [ ] Os testes incluem pelo menos três falhas.
- [ ] Lint permanece verde.

## Evidência e gate

- [ ] Suíte verde sem consultar solução.
- [ ] Execução com os dois fixtures registrada.
- [ ] Pelo menos três commits pequenos.
- [ ] Retrospectiva criada.
- [ ] Fluxo explicado oralmente sem consultar o código.
