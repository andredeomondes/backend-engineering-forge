# ADR 0003 — Progressão por competências e GCP

- Status: aceita
- Data: 2026-11-13
- Complementa: [ADR 0002](0002-java-spring-main-stack.md)

A experiência profissional em TypeScript permite diagnosticar os fundamentos
já dominados. Java/Spring segue como stack principal. Cinco níveis orientam a
prática por evidência e mantêm as fases e os identificadores existentes.
LedgerFlow continua como projeto central Java; projetos menores isolam
problemas de negócio e o Capstone aplica engenharia de produção a um deles.

NestJS tem uma entrega própria com Fastify e comparação focada de adaptadores.
Python continua como automação complementar. GCP passa a orientar cloud:
Cloud Run e Cloud SQL no primeiro deploy; IAM, IaC, GKE e Pub/Sub quando o
problema de operação justificar. As referências anteriores de AWS podem ser
consultadas para transferir conceitos. A curadoria e os briefs serão
materializados em exercícios quando chegar a etapa de prática.

Veja [níveis](../curriculum/competency-levels.md) e
[projetos](../../projects/README.md).
